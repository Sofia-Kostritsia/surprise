ПАКЕТ ОПИТУВАННЯ BAKUGO

Файли:
- index.html — сайт-опитування
- bakugo-art.png — зображення для дизайну
- Code.gs — скрипт, який записує відповіді у Google Sheets

ПІДКЛЮЧЕННЯ ДО ТАБЛИЦІ
1. Відкрий таблицю:
   https://docs.google.com/spreadsheets/d/1VO8qU62UG1tQCokDQ2CtErQa2akHwKqZE44_Rjc6jm4/edit
2. Вибери Розширення → Apps Script.
3. Відкрий Code.gs, заміни вміст кодом із файлу Code.gs і збережи.
4. Натисни Розгорнути → Нове розгортання.
5. Тип: Вебзастосунок.
6. Виконувати від імені: Я (власник скрипту).
7. Хто має доступ: Усі (якщо політика акаунта дозволяє).
8. Натисни Розгорнути, надай запитані дозволи та скопіюй URL вебзастосунку, який закінчується на /exec.
9. У файлі index.html знайди SCRIPT_URL і заміни текст ВСТАВТЕ_URL_ВЕБЗАСТОСУНКУ_APPS_SCRIPT на скопійований URL.
10. Збережи index.html разом із bakugo-art.png і опублікуй обидва файли на хостингу (або відкрий локально для тесту).

Важливо:
- Скрипт додає заголовки, якщо перша вкладка порожня, і записує кожну відповідь новим рядком.
- Для збереження даних вебзастосунок має бути розгорнутий з доступом для тих, хто проходитиме опитування.
- Режим no-cors не дозволяє браузеру прочитати відповідь сервера; повідомлення сайту означає, що запит відправлено, а не незалежно підтверджений запис. Перевір перший тестовий рядок у таблиці.
